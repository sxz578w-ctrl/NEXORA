# NEXORA — نيكسورا

**الشعار:** عوالم متحدة  
**الحزمة الحالية:** 0.1.0-foundation  
**المنصة المستهدفة:** Android  
**المحرك:** Godot 4.x  
**لغة الواجهة:** العربية مع RTL  
**الاتجاه الافتراضي:** Portrait

## حالة المشروع

هذا المستودع يحتوي على النواة البرمجية الأولية للعبة NEXORA، وقد نُقلت الملفات من حزمة التطوير التأسيسية إلى GitHub.

- واجهة عربية بخمسة تبويبات.
- خريطة حملة أولية تتكون من 70 عقدة.
- أنظمة أولية للقتال والبطاقات والندرة والدمج والمكافآت والتطور.
- حفظ محلي مع نسخ احتياطية ونقطة استعادة للمواجهة.
- اختبارات GDScript وفحص عقود ساكن باستخدام Python.

**حدود الإصدار:** هذا أساس قابل للتطوير وليس إصداراً نهائياً. لا يوجد APK منشور أو إعداد Android Export مُعتمد في هذا المستودع حتى الآن. لم يتم إثبات الترجمة أو التشغيل داخل محرك Godot في بيئة البناء الحالية. اجتاز فحص Python الساكن 113 تحققاً؛ وهذا لا يعادل اختبار تشغيل داخل المحرك.

## التشغيل

1. ثبّت Godot 4.x.
2. افتح هذا المستودع كمشروع موجود باستخدام ملف `project.godot`.
3. شغّل المشروع عبر F5.

## الاختبارات

فحص العقود الساكن:

```bash
python3 tests/static_contract_check.py
```

اختبارات GDScript عبر Godot:

```bash
godot --headless --path . --script res://tests/run_tests.gd
```

يمكن أن يكون اسم الملف التنفيذي `godot4` على بعض الأنظمة.
