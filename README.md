# NEXORA — نيكسورا

**الشعار:** عوالم متحدة  
**المستودع:** `sxz578w-ctrl/NEXORA`  
**المنصة المستهدفة:** Android  
**المحرك المخطط:** Godot 4.x  
**لغة الواجهة:** العربية مع RTL

## حالة المستودع

هذا المستودع جرى تهيئته، ويحتوي حالياً على وثيقة التعريف هذه فقط. لم تُرفع ملفات مشروع Godot المصدرية بعد، لذلك لا يمكن استيراده أو تشغيله أو تصديره إلى APK من هذا المستودع في حالته الحالية.

## حالة حزمة التطوير المحلية

توجد حزمة تأسيسية منفصلة لمشروع Godot تتضمن:
- واجهة عربية أولية بخمسة تبويبات.
- خريطة حملة أولية تتكون من 70 عقدة.
- أنظمة أولية للقتال والبطاقات والندرة والدمج والمكافآت والتطور.
- حفظ محلي مع نسخ احتياطية ونقطة استعادة للمواجهة.
- اختبارات GDScript وفحص عقود ساكن باستخدام Python.

اجتاز الفحص الساكن المحلي 113 تحققاً. لم تُشغّل اختبارات GDScript داخل Godot ولم يتم إثبات الترجمة أو التشغيل الفعلي. الحزمة ليست إصداراً نهائياً ولا يوجد APK معتمد.

## الخطوة التالية المطلوبة

رفع ملفات مشروع Godot الفعلية إلى جذر المستودع، ثم إضافة CI لتشغيل فحص Python واختبارات Godot، وإصلاح أي أخطاء تظهر، وبعدها إعداد Android Export واختبار APK على جهاز فعلي.

## الأمان

لا ترفع مفاتيح توقيع Android أو كلمات المرور أو رموز الوصول إلى Git.
