## حد الإصدار

لم يُنشأ APK ولم تُهيّأ مفاتيح توقيع أو أسرار Android. لا يعتبر أي ملف Android قابلاً للإصدار قبل إعداد Android Export والتحقق من APK على جهاز فعلي.

## تصحيح اختبار عقدة المرحلة الثالثة

أظهر أول تشغيل داخل Godot أن اختبار الاستعادة كان يتوقع نوع `puzzle` للمرحلة 3، بينما خريطة العالم تعرّف المرحلة 3 كعقدة `siege`. منطق الاستعادة يعيد حساب نوع العقدة من المرحلة، ولا يثق في قيمة `node_type` المحفوظة. أضيفت طبقة تصحيح ضيقة وآمنة إلى `patches/apply_source_fixes.py`، مع اختبارات Python للتحقق من التصحيح وتكرار تطبيقه ورفض بنية مصدر غير متوقعة. يغيّر اختبار GDScript قيمة الحفظ عمداً إلى `boss` ويتأكد أن النتيجة تطابق `WorldMap.get_node_type(3)`.
